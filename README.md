# NESBYTE Technologies website

A fresh Next.js App Router website for NESBYTE Technologies.

## Stack
- Next.js 15
- React 19
- TypeScript
- CSS design system
- Lucide icons

## Local development
```bash
npm install
npm run dev
```

## Before public launch
1. Confirm the company contact email and add a working enquiry form.
2. Add verified business phone/WhatsApp and social links.
3. Replace project overview cards with approved case studies and genuine results.
4. Confirm the final company legal name and trademark position.
5. Update product availability only when products are actually launched.

The site intentionally does not claim client logos, testimonials, certifications, office addresses, or launched SaaS products that have not been verified.
